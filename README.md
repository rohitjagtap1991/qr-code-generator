# QR Code Generator

A simple, privacy-focused QR code generator. Generate custom QR codes instantly with color customization and multiple download formats.

## Features

- 🎨 **Custom Colors** - Personalize foreground and background colors
- 📐 **Multiple Sizes** - From 256px to 2048px
- 💾 **Download Formats** - PNG and SVG
- 🔒 **100% Private** - All processing happens in your browser
- 📱 **Mobile Responsive** - Works on all devices
- 🌍 **Multilingual** - English and Spanish support
- ⚡ **No Sign-up Required** - Start generating immediately

## Tech Stack

- Pure HTML, CSS, JavaScript (no frameworks)
- QR code generation: qrcode.js
- 100% client-side processing
- No backend required

## Usage

Simply open `index.html` in your browser or visit the live site.

1. Enter your text or URL
2. Customize colors and size
3. Generate and download your QR code

## Privacy

This tool is completely client-side. No data is sent to any server. All QR code generation happens locally in your browser.
