# QR Code Generator

A powerful, privacy-focused QR code generator with support for multiple content types. Generate custom QR codes instantly with advanced features and download in multiple formats.

🌐 **Live Demo:** [https://rohitjagtap1991.github.io/qr-code-generator/](https://rohitjagtap1991.github.io/qr-code-generator/)

## Features

### QR Code Types
- 📝 **Text & URL** - Plain text and website links
- 📱 **WiFi Network** - Share WiFi credentials instantly (SSID + Password + Encryption)
- 👤 **vCard** - Digital business cards with contact information
- 📧 **Email** - Pre-filled email addresses with optional subject and body
- 📞 **Phone** - Direct dial phone numbers
- 💬 **SMS** - Pre-filled text messages

### Customization
- 🎨 **Custom Colors** - Personalize foreground and background colors with hex input
- 📐 **Multiple Sizes** - From 256px to 2048px
- 💾 **Download Formats** - PNG (with quiet zones) and SVG vector formats
- 🎯 **Smart Filenames** - Auto-generated with content type and timestamp

### User Experience
- 📋 **Copy to Clipboard** - One-click copy of generated QR data
- 📥 **Download History** - Track your recently generated QR codes
- 🔒 **100% Private** - All processing happens in your browser, no data sent to servers
- 📱 **Mobile Responsive** - Works perfectly on all devices
- 🌍 **Multilingual** - English and Spanish support
- ⚡ **No Sign-up Required** - Start generating immediately
- ⚙️ **Dynamic Error Correction** - Automatic optimization based on content length

## Tech Stack

- Pure HTML, CSS, JavaScript (no frameworks)
- QR code generation: qrcode.js
- 100% client-side processing
- No backend required

## Usage

Simply open `index.html` in your browser or visit the [live site](https://rohitjagtap1991.github.io/qr-code-generator/).

### Basic Workflow
1. Select QR code type from dropdown (Text, WiFi, vCard, Email, Phone, SMS)
2. Fill in the required information
3. Customize colors and size (optional)
4. Click "Generate QR Code" to preview
5. Download as PNG or SVG, or copy to clipboard

### Use Cases

**Share WiFi Network:**
- Select "WiFi Network" type
- Enter network name (SSID) and password
- Choose encryption type (WPA/WEP/None)
- Generate QR - guests can scan to connect instantly

**Digital Business Card:**
- Select "Contact Card (vCard)" type
- Fill in name, phone, email, company, etc.
- Generate QR - recipients can scan to save contact

**Quick Email Contact:**
- Select "Email" type
- Enter email address, subject, and message
- Generate QR - opens pre-filled email when scanned

## Privacy

This tool is completely client-side. No data is sent to any server. All QR code generation happens locally in your browser.
